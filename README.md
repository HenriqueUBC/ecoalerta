# NEW ERA : GUARDA LIXO

Projeto de intinerario extensionista 2-2026

## COMO RODAR

1. Instale o Node.js com NPM
2. Baixe este repositório usando git ou como arquivo zip
3. Dentro do repositório, execute `npm install`
4. Logo após rode `npm run dev` para rodar o servidor e depois entre no servidor localhost indicado pelo VITE.
